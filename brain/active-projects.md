# Active Projects

## Agentic OS (Current)
- Status: v4.0 Released — Planning v5.0 (Phases 5 & 6)
- Priority: HIGH
- Roadmap: 8 Phases Planned (Phases 1–4 Shipped, Phases 5–8 in Roadmap)

### Shipped Milestones
- **v1.0 (Phase 1)**: Core 3-Agent Engine (`opencode` + `Hermes` + `agy`), 15 Skills, SPA Web Dashboard, APScheduler cron jobs.
- **v2.0 (Phase 2)**: Kanban Board, Goals Tracker, Daily Journal, Smart Router, Agent Health, Learning Analytics, Session Replay.
- **v3.0 (Phase 3)**: Event-Driven Scheduler, Webhooks, Error Dashboard, Circuit Breaker, SQLite FTS5 Memory Search, Auto-Skill Generator.
- **v4.0 (Phase 4)**: Mobile PWA, `agy` (Antigravity) integration, Chat History Search, File Attachments, Memory Knowledge Graph, Code Diff Viewer, 74 Tests.

### Planned for v5.0 (The Jarvis & Autonomy Release)
- **🎙️ Voice Command Center & Desktop HUD**:
  - Hands-free voice control (Whisper STT + Kokoro/Web Speech TTS).
  - Lightweight, cross-platform Tauri v2 desktop companion.
  - Tactile neo-glass widget grid with live voice HUD, waveform, and system metrics.
- **🤖 Visual Agent Studio & Profile Hub**:
  - Interactive visual builder to configure agent personas, system prompts, and capabilities.
  - Transactional sandbox playground to test agent behavior safely.
- **🔄 Autonomous Multi-Agent Chaining**:
  - Automated handoff pipeline: `agy` researches ➔ `opencode` implements ➔ `Hermes` verifies & notifies.
- **🔐 Standard Gateway Auth & Remote Access**:
  - Secure token/JWT API gateway for safe mobile and remote access without exposing localhost unauthenticated.
